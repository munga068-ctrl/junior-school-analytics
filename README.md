# Junior School Analytics

A score entry and exam report analytics tool for schools, built as a React app.

## Features
- Setup: manage classes, learning areas/subjects, student roster, exams, and performance level bands
- Score entry: record marks per exam, class, and subject
- Reports: colour-coded score sheets with totals, means, class rank, and subject performance charts
- Dashboard: quick overview stats

## Files
- `score-report-manager.jsx` — the main React application component
